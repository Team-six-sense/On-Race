# 티켓팅 매크로 사용법

지정한 시각에 자동으로 버튼을 클릭하고, AI가 보안 문제(VQA)까지 풀어주는 티켓팅 자동화 도구입니다.

---

## 처음 한 번만 하면 되는 준비

### 1. Python 설치
- [python.org](https://www.python.org/downloads/) 에서 Python 3.11 이상 다운로드 후 설치
- 설치 시 **"Add Python to PATH"** 체크 필수

### 2. 필요한 프로그램 설치
터미널(맥: 터미널 앱 / 윈도우: 명령 프롬프트)을 열고 아래 명령어를 입력하세요.

```
cd "AI Macro 폴더 경로"
pip install -r requirements.txt
```

### 3. Gemini API 키 발급
1. [Google AI Studio](https://aistudio.google.com/apikey) 접속
2. **"Create API key"** 클릭 → 키 복사

---

## 매번 사용 전 설정

`config.env` 파일을 메모장으로 열고 아래 세 가지를 채워주세요.

```
GEMINI_API_KEY = 여기에_복사한_API_키_붙여넣기
TARGET_URL = 티켓팅_페이지_주소
TARGET_TIME = 티켓팅 날짜/시각
```

### (선택) 프록시로 IP 바꾸기

실제 IP 대신 프록시 IP로 접속하고 싶다면 `proxies.txt.example` 을 복사해 `proxies.txt` 파일을 만들고 한 줄에 하나씩 프록시를 넣어주세요.

```
http://1.2.3.4:8080
http://myuser:mypass@1.2.3.4:8080
socks5://1.2.3.4:1080
```

- 실행할 때마다 목록에서 **하나를 랜덤으로 골라** 그 세션 내내 같은 IP로 접속합니다.
- 파일이 없거나 비어 있으면 프록시 없이 실제 IP로 접속합니다.
- 무료 공개 프록시는 이미 차단된 경우가 많으니, 가급적 **유료 주거용(residential) 또는 모바일 프록시**를 사용하세요.

---

## 실행 방법

터미널에서 아래 명령어 입력:

```
python ticket_macro.py
```

- 프로그램이 실행되면 브라우저가 자동으로 열립니다.
- 티켓 오픈 전까지 **로그인 후 마라톤 신청 페이지에 접속하세요.**
- 지정한 시각이 되면 자동으로 버튼을 클릭합니다.
- 보안 문제(영상 퀴즈)가 나오면 AI가 자동으로 풀어줍니다.
- 대기열 통과 후, 결제는 직접하시면 됩니다.
- 완료 후 엔터를 누르면 브라우저가 닫힙니다.
