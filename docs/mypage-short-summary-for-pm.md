# MyPage Short Summary

기준일: 2026-03-24

PM/디자이너 공유용 짧은 버전이다.

## 지금 되는 것

- 신청내역 페이지는 백엔드 계약이 정리되어 있다.
- 계정 화면용 API가 있다.
- 계정 화면에서 이름, 이메일, 전화번호, 비밀번호 변경 가능 여부를 보여줄 수 있다.
- 본인인증 상태를 보여줄 수 있다.
- 마케팅 수신 동의 상태를 보여주고 변경할 수 있다.
- 배송지 목록/추가/수정/삭제/기본 배송지 변경 API가 있다.

## 현재 기준 화면별 사용 API

- 신청내역: `GET /mypage/entries`
- 계정 정보: `GET /mypage/account`
- 기본 배송지 요약: `GET /mypage/address`
- 배송지 목록/관리: `/addresses`

## 이번 범위에서 일부러 뺀 것

- 주문/결제내역 화면
- 결제 상세 화면
- 결제 완료 화면
- 신청내역과 배송지 연결
- 취소/환불/교환 플로우
- 외부 본인인증 연동

## 주의할 점

- `/mypage/address`는 주소 목록이 아니라 기본 배송지 요약이다.
- 주소 목록과 수정/삭제는 `/addresses`를 사용한다.
- 신청내역은 이번 릴리즈 기준의 축소 범위 계약이라, 결제 관련 CTA를 중심으로 만들지 않는다.

## 현재 진행도 체감

- 마이페이지 백엔드 전체: 약 85%
- 신청내역: 거의 완료
- 계정 화면: 거의 완료
- 배송지: 거의 완료
- 남은 일: 프론트 연결과 QA 정리

## 한 줄 요약

이번 마이페이지는 `신청내역`, `계정`, `배송지`를 각각 분리된 API로 붙이는 구조이고, 주문/결제는 이번 출시 범위에서 제외한 상태다.
